# NftMega

NftMega is a decentralized, real-time data aggregation engine for high-performance NFT rendering and distribution on a global platform.

With NftMega, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/NftMega.git`
2. `cd NftMega`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
